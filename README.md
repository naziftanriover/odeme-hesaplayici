# Ödeme Hesaplayıcı (SOLİBET)

Kasiyerin STG / USD / EUR / TL karışık ödemelerde "ne kadar ödedim, ne kadar kaldı" hesabını yapan basit araç. Veri kaydetmez, hiçbir sisteme bağlı değildir.

- Hesap mantığı: `app.js` içindeki saf fonksiyonlar (`hesaplaToplam`, `hesaplaKalan` vb.)
- Güncelleme: kodu değiştir → `sw.js` içindeki `SURUM` numarasını artır → `git push`
